# Demo Script

1. Start with the three simple demos and explain the ladder.
2. Open the comprehensive workflow surface only after the pillars are clear.
3. Sign in with Security Key identity proof.
4. Pick one intent, such as `approveSensitiveAction` or `releasePrizeCode`.
5. Show the Ledger validation mapped to that intent.
6. Trigger the sensitive action that requires fresh approval.
7. Show optional wallet proof as additive, not primary identity.
8. Show local/off-chain app state.
9. Capture dogfood feedback about the approval or wallet moment.
10. Close by mapping the receipts back to the three pillar demos.
